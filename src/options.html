Mercado — aquisição automática

Consulta os anúncios do Mercado pela API do site (com o seu login no twish.com.br) e compra no máximo um anúncio por verificação, o mais barato que passar nos critérios. Desliga sozinho com saldo insuficiente.
Cada verificação varia ±25%. Mais rápido pega mais ofertas, mas é um ritmo mais fácil de notar.
